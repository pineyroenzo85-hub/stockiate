Coopper Stockiate es responsable del tratamiento de los datos personales recopilados a través de stockIAte.

1. Información que recopilamos

stockIAte recopila y procesa la siguiente información:

  • Datos de productos (nombre, marca, SKU, precio)
  • Información de inventario y stock
  • Registros de ventas y transacciones
  • Datos de usuarios (email, rol, nombre)
  • Información de contacto para notificaciones (teléfono de WhatsApp)

2. Cómo usamos la información

La información se utiliza exclusivamente para:

  • Gestionar el inventario y stock del negocio
  • Procesar transacciones de ventas
  • Enviar notificaciones de alertas (stock crítico, vencimientos)
  • Generar reportes y análisis de ventas
  • Administrar acceso de usuarios al sistema

3. Almacenamiento de Datos

Los datos se almacenan en una base de datos asociada al sistema, implementando medidas de seguridad técnicas y organizativas destinadas a evitar accesos no autorizados.

stockIAte puede utilizar cookies o mecanismos equivalentes necesarios para mantener sesiones de usuario y garantizar el funcionamiento y la seguridad del sistema.

4. Protección de datos

Implementamos las siguientes medidas de seguridad:

  • Contraseñas hasheadas para usuarios
  • Sesiones de servidor seguras
  • Acceso controlado por rol de usuario
  • Encriptación de credenciales sensibles

5. Servicios Externos y Transferencias de Datos

stockIAte puede procesar datos a través de los siguientes servicios externos:

Roboflow (Detección de Productos)

Cuando se utiliza la función de reconocimiento automático de productos mediante imágenes, las imágenes capturadas se envían a Roboflow exclusivamente para realizar la detección visual del producto. Estas imágenes se procesan únicamente con el propósito de identificar el artículo y no se almacenan con fines secundarios.

WhatsApp Business Platform (Meta)

Los números de teléfono cargados por el propietario se utilizan para enviar notificaciones automáticas (alertas de stock crítico, vencimientos, resúmenes diarios) a través de la plataforma WhatsApp Business de Meta. El teléfono se procesa exclusivamente para esta finalidad.

Groq AI (Asistente de Inteligencia Artificial)

Las consultas realizadas al asistente de IA integrado pueden ser procesadas por Groq para generar respuestas basadas en datos del sistema. Estas consultas se procesan bajo términos de confidencialidad.

6. Derechos del Usuario

El propietario del negocio tiene derecho a:

  • Acceder a todos sus datos en cualquier momento
  • Rectificar la información incorrecta o incompleta
  • Solicitar eliminación de datos cuando corresponda, de acuerdo con las obligaciones legales y la retención requerida
  • Archivar productos como función del sistema para mantener el historial de ventas sin que el producto aparezca en operaciones activas

7. Conservación de Datos

Los datos se conservarán durante el tiempo necesario para prestar las funcionalidades del sistema y mientras exista una relación activa con el negocio.

El historial de ventas, transacciones y auditoría se conservará según los requisitos legales y fiscales aplicables, incluso después del archivado de productos.

Los propietarios pueden solicitar la eliminación de datos específicos cuando corresponda, sujeto a las obligaciones legales de retención.

8. Cambios a esta política

Nos reservamos el derecho de actualizar esta política en cualquier momento. Los cambios entrarán en vigor inmediatamente al ser publicados.
